# Поиск и проверка дат с помощью регулярных выражений
 форматы:
- `ДД.ММ.ГГГГ` — например, `17.11.2026`
- `ДД/ММ/ГГГГ` — например, `17/11/2026`
- `ДД-ММ-ГГГГ` — например, `17-11-2026`
- `ГГГГ-ММ-ДД` — например, `2026-11-17`

## Возможности
- поиск дат d тексте
- чтение TXT 
- загрузка страниц по HTTP/HTTPS
- проверка календарной корректности
- сохранение, просмотр, поиск по ID и удаление записей
- полная очистка хранилища


## ответственность слоёв

- (`data_layer`): `DateRecord` — модель одной найденной даты
-  `DateRepository` задаёт общий контракт. `MemoryDateRepository` хранит данные в памяти, `JsonDateRepository` — в JSON-файле.
-  `DateService` выполняет поиск, проверку дат и операции над записями. Он зависит от абстрактного `DateRepository`, а не от конкретного хранилища. `TextDataSource` отвечает за чтение TXT и получение содержимого URL.
- (`main.py`): показывает меню, получает пользовательский ввод и выводит результаты
## Зауск

Требуется Python 3.9 или новее.
При первом сохранении программа создаст `dates.json` 

## Тестирование

Из корневой папки:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют форматы дат, некорректные календарные даты, повторные вхождения, CRUD-операции обоих репозиториев, чтение TXT и загрузку URL (сетевой запрос имитируется)
Результаты фактического запуска  в `TEST_RESULTS.txt`
